# 🎅 VK Бот «Морозко» — Сказка В Дом

Бот для бронирования Деда Мороза и Снегурочки на дом. Работает на Long Poll API ВКонтакте.

## 🚀 Возможности
- Мульти-дети: бронирование для 1, 2, 3 и более детей за один раз.
- Пошаговая воронка: от выбора пакета до оплаты.
- Поддержка промокодов и реферальной программы.
- Режим оператора (передача диалога живому человеку).
- Автоматические напоминания за 24 часа и за 2 часа до визита.
- Опциональная интеграция с Google Sheets для логов броней.

## 🛠 Технологии
- Python 3.11+
- [vkbottle](https://github.com/vkbottle/vkbottle) — фреймворк для VK API
- Google Sheets API (gspread) — для хранения логов
- Bothost — хостинг для бота

## 📂 Структура проекта
- `main.py` — точка входа, роутер и логика воронки.
- `texts.py` — все тексты бота (правит маркетолог).
- `keyboards.py` — клавиатуры.
- `state.py` — логика слотов, броней и промокодов (в памяти).
- `sheets.py` — модуль интеграции с Google Sheets.
- `requirements.txt` — зависимости.

## 🔐 Переменные окружения
Для работы бота в Bothost (или на любом другом хостинге) необходимо задать следующие переменные:

| Переменная | Описание | Обязательно |
|------------|----------|-------------|
| `VK_GROUP_TOKEN` | Токен сообщества ВК (права: «Сообщения» + «Управление») | Да |
| `VK_GROUP_ID` | Числовой ID сообщества | Да |
| `ADMIN_VK_ID` | Ваш личный VK ID для уведомлений оператора | Нет (если нужен режим оператора) |
| `HOLD_MINUTES` | Время удержания слота (по умолчанию 15) | Нет |
| `GOOGLE_SHEET_ID` | ID таблицы для логов | Нет |
| `GOOGLE_SA_JSON_B64` | JSON-ключ сервисного аккаунта Google в base64 | Нет |

## 📦 Установка и запуск (Bothost)
1. Загрузите код в этот репозиторий.
2. Создайте бота на Bothost, выберите платформу VK и подключите этот репозиторий.
3. Добавьте переменные окружения в панели Bothost.
4. Нажмите «Запустить».

## ⚠️ Важно
- В MVP-версии оплата эмулируется (кнопка «Оплатить»). Для реальных платежей потребуется интеграция с VK Pay или ЮKassa (Stage 5).
- Слоты и брони хранятся в памяти. При перезапуске бота они сбрасываются, но оплаченные брони восстанавливаются из Google Sheets (если подключено).
